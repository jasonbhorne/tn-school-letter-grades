# Tennessee School Letter Grades: A Machine Learning Analysis

This repository contains the code and data for a machine learning analysis of Tennessee public school letter grades, exploring what factors drive school performance ratings.

## Paper

[A Machine Learning Approach to Analyzing Tennessee Public School Letter Grades](A%20Machine%20Learning%20Approach%20to%20Analyzing%20Tennessee%20Public%20School%20Letter%20Grades%20Final%20Submission%204-23-2024.pdf) (PDF)

## Analysis

### Supervised Learning (`Letter_Grade_Analysis.ipynb`)
- Random Forest, Gradient Boosting, and SVM classifiers
- Feature importance analysis across letter grade components
- Cross-validation and model comparison

### Unsupervised Learning (`Unsupervised.ipynb`)
- K-Means and hierarchical clustering of school profiles
- PCA dimensionality reduction
- Cluster characterization and visualization

## Data

Analysis uses publicly available data from the Tennessee Department of Education, including school-level assessment results, demographics, and accountability metrics.

## Requirements

- Python 3.8+
- pandas, scikit-learn, matplotlib, seaborn
- jupyter
